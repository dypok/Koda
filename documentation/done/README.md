# 📁 Repositorio de Entregables y Evidencias (`documentation/done/`)

> Este directorio almacena la bitácora técnica de entregables formalizados para cada Historia de Usuario y tarea de ingeniería en Koda 🦊.

---

## 🗂️ Subdirectorios de Entregables

```
documentation/done/
├── backend/    # Entregables de Backend (backend-[number]-[nombre].md)
├── frontend/   # Entregables de Frontend (frontend-[number]-[nombre].md)
└── other/      # Entregables transversales: DevOps, Database, Tooling, Gobernanza (other-[number]-[nombre].md)
```

---

## 📋 Estándar de Nomenclatura

- **Backend:** `backend-[number]-[nombre].md` (ej. `backend-01-auth-supabase-setup.md`)
- **Frontend:** `frontend-[number]-[nombre].md` (ej. `frontend-01-onboarding-wizard.md`)
- **Other:** `other-[number]-[nombre].md` (ej. `other-01-docker-redis-governance.md`)
